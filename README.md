# ParkAI 🚗

Ein KI-gestützter Einparkassistent als Informatikprojekt.

## Projektbeschreibung

ParkAI ist eine Python-Web-App, die mithilfe von Machine Learning
Fahrzeuge in Bildern erkennt und eine vereinfachte
Einpark-Simulation erstellt.

## Technologien

- Python
- Streamlit
- YOLO
- OpenCV
- NumPy
- Matplotlib

## Funktionen

- Upload von Parklücken-Fotos
- KI-gestützte Objekterkennung
- Eingabe von Fahrzeugmaßen
- Geometrische Parklückenanalyse
- Einpark-Simulation

## Installation

Repository herunterladen:

    git clone DEIN_GITHUB_REPOSITORY

In den Projektordner wechseln:

    cd ParkAI

Abhängigkeiten installieren:

    pip install -r requirements.txt

App starten:

    streamlit run app.py

## Hinweis

ParkAI ist ein experimenteller Prototyp
für ein Informatikprojekt und kein
sicherheitsgeprüfter Fahrassistent.
